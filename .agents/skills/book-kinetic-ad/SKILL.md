# 도서 키네틱 광고

**단어의 움직임이 메시지를 전달하는 광고.** 승인본에서 큰 활자·읽는 정지·의미 있는 연결을 배우되, 새 책의 구성과 음악은 새로 선택한다. 색과 제목만 바꾼 복제본을 만들지 않는다. 사용자의 명시적 요구와 같은 캠페인의 일관성 요청이 기본값보다 우선한다.

## 작업 시작

HyperFrames로 시작하고 이 스킬을 도서 광고의 스타일·선곡 지침으로 적용한다. 기존 영상의 좁은 수정은 해당 범위만 수행한다. 이미 정해진 사항을 다시 질문하지 않으며, 제작 요청은 MP4와 편집 소스까지 마친다.

- **새 책·새 콘셉트:** [스타일과 구성](references/style-and-rhythm.md)을 읽는다. 제공된 소개·목차·출판사 자료에서 독자, 문제, 책의 변화, 근거를 확인하고 중심 메시지를 고른다. 표지만 있으면 확인 가능한 사실로 진행한다.
- **새 선곡·BGM 교체:** [상업용 BGM 선택](references/music-selection.md)을 읽고 검색·청취·이용 조건 확인·편집·삽입까지 수행한다. 무음 요청은 따른다.
- **구현·수정:** [구현 및 검증](references/implementation.md). 기준 영상과 파일 위치는 [프로젝트 연결 정보](references/project-map.md).

로컬에 `assets/reference-contact.jpg`와 `assets/reference.mp4`가 있으면 필요한 구간을 확인해 실제 이동과 정지를 익힌다. 이 미디어는 GitHub에 포함하지 않는 선택 자료다. 없으면 스타일·구성 지침과 새 도서 자료로 진행하며, 참조 영상 확보 때문에 제작을 멈추지 않는다. 승인본은 품질 참고이며 모든 새 책의 장면표가 아니다.

## 유지할 기본값

- 15–20초, 기본 18초 / 세로 1080×1920 / 60fps. 메시지와 요청에 맞춰 조정한다.
- 주 카피 Paperlogy Black(900), 부 카피 Paperlogy Bold(700). 실제 로컬 폰트에서 벡터 경로를 만든다.
- 핵심 타이포와 이동은 Lottie로 구현한다. 의미 있는 연결을 중심으로 하고 Trim Paths 등 효과는 필요한 곳만 쓴다.
- 색과 명암 비중은 표지에서 정한다. 강한 포인트 1–2개와 지면·활자색을 활용하며, 모든 표지를 큰 원색 면으로 바꾸지 않는다.
- 한 비트에 한 메시지. 빠른 이동 뒤 읽는 정지를 확보하고, 원본 표지·상표·인물의 모습을 보존한다.
- 그림은 투명 PNG·SVG·원본 픽셀 마스크 등으로 분리해 사용한다. 적절한 기존 자산을 먼저 쓰고 생성 재현을 기본으로 삼지 않는다.
- 무음 지시가 없으면 해당 도서와 연출에 어울리고 배포 용도의 상업 이용이 확인된 BGM을 포함한다. **Funkee Monkeee와 120BPM은 특정 승인본의 선택이지 공통 기본값이 아니다.**

## 매번 다른 결과를 만드는 선택

새 독립 작업은 최근 작업의 BRIEF·장면표·최종 프레임을 가볍게 대조한다. 도입, 활자 배치, 장면 연결, 제품 등장, 음악 중 무엇을 이어받고 무엇을 바꿀지 정한다. 도입·공간 구성·연결 방식 중 두 축 이상을 바꾸는 것을 출발점으로 삼되, 책의 의미와 사용자의 일관성 요구를 우선한다.

카피만 다른 유사안 대신 서로 다른 접근 2–3개를 내부에서 짧게 비교하고 가장 적합한 하나를 선택한다. 예: 결과 먼저 보여주기, 구체적인 상황에서 시작하기, 핵심 단어가 계속 변형되기. 이는 예시이며 순환 템플릿이 아니다. 선택 이유와 직전 작업과의 차이를 BRIEF의 `연출 선택`에 짧게 남긴다. 선택지를 매번 사용자에게 고르게 하지 않는다.

같은 질문형 도입 → 세 줄 중앙 정렬 → 가로 밀기 → 제목 축소 → 표지 구조가 반복되면 장면 설계로 돌아간다. 색·서체 크기·속도만 바꾸거나 무작위 효과를 추가하는 것으로 해결하지 않는다. 좁은 수정에는 이 다양화 절차를 적용하지 않는다.

## 시작 파일

새 작업은 다음 순번의 작업 폴더에 공통 기술 파일만 마련한다. 순번은 루트 AGENTS.md와 기존 작업 목록을 확인한다.

```sh
python3 .agents/skills/book-kinetic-ad/scripts/seed_project.py --target projects/003-new-book/videos/main
```

기본 시작본에는 이전 책의 장면·표지·아이콘·BGM이 없다. BRIEF를 채우고 `scripts/composition.mjs`에 새 구성과 선택한 음원을 지정한 뒤 빌드한다. 승인본의 기술 재현을 명시적으로 원하는 경우에만 `--reference`를 쓴다. 기존 승인본 자체를 수정할 때만 그 생성기의 필요한 부분을 고친다.

## 완료 기준

- 독자가 얻는 변화가 전달되는지, 카피의 근거가 있는지, 새 독립 작업의 구성과 선곡이 직전 결과를 관성적으로 반복하지 않는지 확인한다.
- 읽는 홀드와 등장·교체·표지 전환의 중간을 실제 프레임으로 확인한다. 글자 잘림, 겹침, 잔상을 수정한다.
- 분리 자산을 색 배경에서 검사하고 서체·비례 변경 후 글리프 폭과 자간을 확인한다.
- 선택 BGM의 실제 사용 구간을 영상과 함께 확인한다. 곡·조건·사용 구간은 MUSIC.md에, 중요한 화면 착지와 음악 시점은 장면표에 남긴다.
- 실제 MP4의 길이·영상·오디오·디코드를 확인하고 소스·최종 파일·문서를 맞춘다. 음원 원본의 소스 패키지 포함 여부는 해당 이용 조건을 따른다.
- 완성 영상을 먼저 링크하고 핵심 결정만 짧게 설명한다. 자동 검사 통과를 디자인·음악 품질 판단으로 대신하지 않는다.

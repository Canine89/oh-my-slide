# 도서마다 다른 카피와 연출

## 카피를 고르는 기준

제공 자료에서 독자·문제·책이 제공하는 변화·실제 근거를 먼저 정리한다. 중심 약속 하나를 고른 뒤 필요한 카피만 남긴다. 소개·목차·출판사 자료가 있으면 표지의 문구 나열에서 멈추지 않는다. 주장과 근거 위치를 BRIEF 또는 카피 문서에 연결한다. 도서에 없는 성과·무료 혜택·후기를 만들지 않는다.

숫자나 저자 정보는 약속을 증명할 때 쓴다. 예를 들어 내 교실 도구 제작이 주제라면 저자 수보다 실제로 만들 앱의 종류가 더 직접적일 수 있다. 반대로 저자의 권위가 핵심이면 저자 정보가 앞설 수 있다. 질문형 도입·문제 해결형 서사를 모든 책에 강제하지 않는다.

## 변주를 선택하는 방법

최근 작업의 BRIEF와 장면표를 읽고 반복된 도입·배치·전환·엔딩·음원을 파악한다. 기록이 없으면 가까운 완성본 하나만 확인한다. 새 독립 작업의 접근 2–3개를 짧게 비교하고 책에 맞는 하나를 선택한다. 아래 표는 조합 재료이지 매번 순서대로 쓰는 프리셋이 아니다.

| 선택 축 | 가능한 접근 | 고르는 기준 |
|---|---|---|
| 도입 | 결과물 먼저, 상황 한 장면, 예상 뒤집기, 짧은 선언, 질문, 핵심 숫자 | 독자가 즉시 이해할 이유 |
| 공간 | 화면을 가로지르는 단어, 좌우 대화, 가장자리에서 모이는 활자, 표지를 둘러싼 글자, 한 단어의 크기 변화 | 카피의 의미와 표지의 구도 |
| 연결 | 단어 유지·동사 교체, 글자 조합, 같은 위치의 의미 전환, 그림이 다음 문구를 밀어냄, 물체·활자의 형태 연결 | 앞 장면이 다음 장면을 시작시키는 방식 |
| 리듬 | 빠른 압축 뒤 긴 홀드, 일정한 박자에 한 번의 정지, 점점 모였다가 한 번에 해소 | 읽을 양과 선택한 음악 |
| 상품 등장 | 첫 등장부터 유지, 중간에 증거로 제시, 마지막 핵심 단어와 결합, 카메라가 표지로 이동 | 책을 언제 알아야 메시지가 이해되는가 |

장면 개수·몇 초에 제목이 나오는지·그림 위치를 고정하지 않는다. 제목이 화면 중앙에 세 줄로 놓이고 같은 방향으로 사라지는 장면을 연속해서 쓰지 않는다. 그래도 중앙 정렬이나 동일한 엔딩이 가장 적합한 경우에는 사용하되 다른 의미 있는 축에서 변주한다.

BRIEF의 `연출 선택`에는 핵심 접근, 주된 연결 방식, 음악 성격, 최근 작업과 다른 점을 2–4문장으로 남긴다. 별도 전역 이력 시스템이나 무작위 배정표를 만들 필요는 없다. 시리즈 통일·같은 스타일 유지가 명시되었으면 그것을 우선한다.

## 활자와 그림

글자가 주인공이며 그림은 반응·상황·전달을 보조한다. 큰 단어와 작은 동사/설명을 번갈아 써 시선이 이동하게 한다. 1080px 폭에서 주 단어 200–470px, 부 카피 60–85px는 참고 범위다. 실제 글리프 폭을 재고, 글자 수에 맞게 행·비례를 정한다. 모든 글자를 세로로 늘리는 것도 피한다.

Paperlogy Black/Bold를 실제 폰트에서 추출한다. 작은 글자에는 대형 활자용 음수 자간을 그대로 적용하지 않는다. 한 비트에는 주 카피 한 덩어리와 필요한 경우 짧은 부 카피만 둔다. 영어 장식·매 장면 출판사명·진행 표시는 습관적으로 붙이지 않는다.

진입 0.2–0.45초, 착지 후 0.6–1.3초는 리듬의 출발점이며 정해진 길이가 아니다. 긴 문구는 읽는 시간을 늘리거나 줄여 쓴다. 가속·감속·짧은 반동을 쓰되 모든 장면의 진입 방향과 튕김을 통일하지 않는다. 무음으로도 읽히고 음악과 함께 보면 중요한 착지가 느껴져야 한다.

표지의 주조색뿐 아니라 밝고 어두운 면적, 활자의 굵기·비례, 여백과 인물의 방향을 본다. 밝은 지면과 검정 활자가 핵심인 표지를 원색 배경으로만 덮지 않는다. 배경·활자의 대비를 따로 확인한다.

분리 자산은 적절한 기존 PNG·SVG·원본 마스크를 먼저 검토한다. 원본 인물의 얼굴·의상·포즈 일치가 중요하면 생성으로 다시 그리지 않는다. 체커보드 RGB를 투명 이미지로 착각하지 않는다. 흰 얼굴·옷·화면의 내부를 잘못 지우지 않는다. 브랜드 아이콘은 실제 자산을 쓰며 책에 없는 플랫폼 혜택을 추가하지 않는다.

## 장면표와 음악

장면표는 `시간 / 메시지 / 주요 동작 / 읽는 구간 / 음악과 만나는 시점` 정도면 충분하다. 음악 선택은 [music-selection.md](music-selection.md)를 따른다. 곡을 정한 뒤 의미가 바뀌는 지점과 제품 착지를 강박·악기 진입·쉼에 맞춘다. 모든 단어를 같은 간격에 배치하지 않는다.

전체가 18초라도 6장면이나 120BPM일 필요가 없다. 제품·제목을 읽을 안정적인 구간은 확보하되 ‘14초부터 표지’로 고정하지 않는다. 표지 진입, 최종 자세 고정, 읽는 홀드, 음악 감쇠를 구분한다.

## 레퍼런스 사용

승인본의 유용한 원리는 큰 글자·명료한 메시지·빠른 이동 뒤의 정지·타이포와 상품의 연결이다. 승인본의 질문, 카카오톡 장면, 5개 삽화, 좌표와 색은 다른 책에 복사할 내용이 아니다.

사용자가 새 레퍼런스를 주거나 새 방향에 실제 도움이 될 때만 추가 조사한다. `구간 / 활자 비례 / 이동·정지 / 소리의 역할 / 가져올 원리`를 짧게 기록한다. 자막은 설명을 이해하는 자료이며 움직임과 음악의 평가는 실제 구간으로 확인한다. 여러 레퍼런스 수집을 매 작업의 의무로 만들지 않는다.

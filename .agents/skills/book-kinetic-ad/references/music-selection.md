# 상업용 BGM 검색·선택·삽입

## 언제 새로 찾는가

새 책이나 새 콘셉트에는 그 작업의 독자·표지·연출에 맞는 음악을 고른다. 최근 사용곡이 폴더에 있다는 이유만으로 재사용하지 않는다. 특정 곡·음악 유지·같은 캠페인 소리가 명시되었거나 기존 영상의 좁은 수정이면 그 결정을 유지한다. 사용자가 새 곡을 지정하지 않았다는 이유로 이전 곡 승인을 새 책에 확대하지 않는다.

상업용 BGM을 고르는 일은 통상 제작에 포함된다. 무료로 사용 가능한 곡을 우선 찾아 적합한 하나를 스스로 선정·삽입한다. 매번 선곡 승인을 다시 요구하지 않는다. 유료 구매·새 구독이 필요해도 기존 비용 승인이 없다면 무료 후보부터 검토하고, 결제가 꼭 필요한 경우에만 구체적인 곡과 비용을 확인받는다.

## 검색과 청취

HyperFrames의 `media-use`로 기존 자산을 확인하고 검색·로컬 채택을 수행한다. 캐시는 후보이지 선택 결과가 아니다. 필요한 웹 조사와 공식 다운로드는 사용 가능한 브라우저·도구로 수행한다. 후보 설명이나 파일명만으로 선곡하지 않는다.

1. 이번 광고의 음악 역할을 먼저 정한다. 예: 가볍고 호기심 있는 클릭·퍼커션, 자신감 있는 베이스 그루브, 따뜻한 어쿠스틱, 절제된 전자음. 항상 펑크·브라스·120BPM으로 시작하지 않는다.
2. 분위기와 악기 구성이 다른 후보 2–3곡의 실제 사용할 구간을 청취한다. 보컬 간섭, 타격감, 전개 밀도, 읽는 시간, 표지 착지에 쓸 종료 지점을 비교한다. 후보 수를 채우느라 부적합한 곡을 다운로드하지 않는다.
3. 곡별 공식 이용 조건을 확인한 후보 중 가장 적합한 하나를 선택한다. 곡 제목·작곡가·트랙 ID·선택 이유·직전 곡과의 차이를 짧게 기록한다. 같은 곡이 최선이면 재사용 이유를 남긴다.
4. 정식 파일을 로컬 `assets/music/`에 저장하고 실제 원본 구간을 지정해 편집한다. 자동 BPM 추정은 참고로만 쓰고 첫 강박과 착지를 듣고 확인한다.

실제 오디오 재생·청취가 불가능한 환경에서는 듣고 골랐다고 주장하지 않는다. 확보된 정보와 한계를 밝히고 청취 가능한 경로로 계속 진행한다. 음악 확보가 실패했다고 임의의 코드 합성음이나 무음 완성본으로 대체하지 않는다. 다른 확인 가능한 무료 출처를 먼저 검토한다.

## 공식 출처와 사용 조건

아래는 검색 출발점이며 전체 트랙에 대한 영구 허용 목록이 아니다. **다운로드 시점에 곡 페이지와 적용 라이선스 원문을 확인**한다. ‘무료’, ‘royalty-free’, 검색 결과의 ‘no copyright’만으로 상업 광고에 쓸 수 있다고 판단하지 않는다.

| 출처 | 확인할 자료 | 선택 시 주의할 범위 |
|---|---|---|
| [Mixkit Music](https://mixkit.co/free-stock-music/) | 곡의 제목·ID와 [Stock Music 라이선스](https://mixkit.co/license/#musicFree) | 공식 FAQ는 온라인 광고·SNS 사용을 안내하며 TV·라디오 방송 등은 제외한다. 배포 매체를 대조한다. |
| [Pixabay Music](https://pixabay.com/music/) | 개별 곡 페이지, [요약](https://pixabay.com/service/license-summary/), [약관](https://pixabay.com/service/terms/), 제공되는 다운로드 증명서 | 상업적 영상 사용 조건과 별도 표시를 확인한다. [공식 FAQ](https://pixabay.com/service/faq/)의 Content ID 안내도 참고한다. |
| 기타 작곡가·공식 음원 라이브러리 | 곡에 적용되는 라이선스 원문과 다운로드/구매 기록 | 유료 광고·상업 사용·편집 허용이 명확한 후보만 선택한다. |

이 표의 안내 확인일은 2026-09-09이며 다음 선곡 시 다시 확인한다. 비상업용·개인용·편집 금지·플랫폼 한정 조건이 작업과 맞지 않으면 후보에서 제외한다. 출처 표기가 필요하면 실제 배포 설명·크레딧에 사용할 정확한 문구를 전달한다. 저작권 표시를 영상에 임의로 작게 숨기지 않는다.

Content ID 등록은 라이선스 허용 여부와 별개다. 등록 여부와 증명서 제공 여부를 확인하고 같은 수준의 음악이라면 처리 부담이 작은 후보를 우선한다. 공식 증명서나 다운로드 기록을 보존하며 ‘클레임이 절대 없다’고 보장하지 않는다. 곡 페이지의 예외·권리 상태가 불명확하면 다른 후보를 선택한다.

완성 영상에 음악을 결합하는 권리와 음원 파일 자체를 재배포하는 권리는 구분한다. 공개 스킬 자산·음악 라이브러리로 곡을 묶어 배포하지 않는다. 편집 소스 ZIP에 원본/편집 음원을 넣어 전달할 수 있는지도 확인한다. 허용되지 않으면 소스에는 취득 링크와 사용 구간을 남기고 해당 파일 제외 사실을 알린다. 로컬 편집 프로젝트와 최종 MP4는 요청된 범위에서 완성한다.

## 영상에 맞추기

선곡과 사용 구간을 정한 뒤 장면의 강한 착지를 맞춘다. 제목·핵심 단어·표지가 드러나는 시점을 곡의 강박, 악기 진입 또는 짧은 쉼과 연결한다. 장면 개수나 컷 길이를 곡 때문에 기계적으로 통일하지 않는다.

음악 시작은 구간의 자연스러운 첫 박에서, 종료는 가능하면 구절의 마무리나 안정적인 여운에서 잡는다. 필요하면 마지막 읽는 홀드 동안 자연스럽게 감쇠한다. 너무 긴 도입·큰 보컬·문장을 읽기 어려운 과밀한 편곡은 피한다. 편집·믹싱은 `media-use`와 필요 시 `hyperframes-audio`를 적용한다.

BGM은 HTML의 별도 audio 요소로 배치하고, 편집한 파일 경로·길이·음량을 소스에 반영한다. 다른 곡과 이전 완성 믹스가 겹치지 않게 한다. 최종 MP4를 소리와 함께 확인하고 오디오 스트림·길이·클리핑·페이드 끝을 검사한다. 파형 검사나 오디오 스트림 존재만으로 음악의 적합성을 통과시키지 않는다.

- 출처 표기 필요 여부와 문구 / Content ID 표시 / 증명서·다운로드 기록의 로컬 위치
- 소스 패키지에 음원 포함 가능 여부
- 원본·편집본 로컬 경로 / 원곡의 시작–종료 구간 / 편집본 길이 / 페이드·음량
- 이 곡을 고른 이유 / 실제로 확인한 템포 또는 박자 시점 / 핵심 화면과 맞춘 시점

정보가 없는 항목은 확인하지 못했다고 적는다. 확인하지 않은 조건을 ‘문제없음’으로 채우지 않는다.
